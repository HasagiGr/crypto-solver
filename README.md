# CryptoSolver

Telegram-бот для решения задач по асимметричной криптографии (RSA, Эль-Гамаль) и сопутствующей теории чисел. Написан во время обучения по направлению «Информационная безопасность» в Финансовом университете; доступ ограничен вайтлистом из ~13 пользователей — бот использовался группой однокурсников для проверки решений домашних задач.

## Архитектура

Решение разбито на два независимых проекта:

- **Crypto** — библиотека криптографических алгоритмов и теоретико-числовых функций, не зависящая от Telegram и вообще от способа взаимодействия с пользователем;
- **CryptoSolver** — тонкая Telegram-обвязка поверх библиотеки Crypto: ведёт диалог с пользователем, разбирает текстовый ввод, вызывает нужный метод и форматирует ответ.

Такое разделение позволяет использовать `Crypto` отдельно — например, в консольном приложении или тестах — без Telegram вообще.

## Шифры

- **RSA** (`СipherRSA.cs`) — шифрование и дешифрование; закрытая экспонента `d` вычисляется автоматически из открытой экспоненты `e` и модуля `n` через функцию Эйлера и поиск обратного элемента.
- **El Gamal** (`CipherElGamal.cs`) — шифрование с автоматическим поиском минимальной образующей циклической группы поля (не нужно подбирать генератор вручную).
- **RSA Банк-Клиент** (`CipherRSABank.cs`) — симуляция протокола подписи и шифрования сообщения между двумя сторонами с разными ключевыми парами (Клиент → Банк или Банк → Клиент), с проверкой корректности через сверку исходного и восстановленного сообщения (`IsCorrect()`).

## Свойства

Раздел-справочник: по запросу бот присылает шпаргалки (свойства RSA, Эль-Гамаля, сравнений, малая теорема Ферма, теорема Эйлера) — краткое сопровождение к лекционному материалу, без вычислений.

## Калькулятор

17 отдельных функций теории чисел, доступных из бота:

- разложение на простые множители — методом пробных делений и методом Ферма;
- тест Ферма на простоту числа;
- НОД, функция Эйлера;
- быстрое возведение в степень по модулю (через двоичное разложение показателя) и умножение по модулю;
- решение сравнения `ax ≡ b (mod m)` и системы сравнений (аналог Китайской теоремы об остатках);
- поиск обратного элемента по модулю — через расширенный алгоритм Евклида (метод подходящих дробей);
- поиск минимальной образующей циклической группы поля;
- оценка размера хеша и вероятности коллизии (парадокс дней рождения);
- оценка вероятности некорректного шифрования RSA при модуле, раскладывающемся более чем на два множителя.

## Как устроен диалог

Бот ведёт пользователя по дереву меню: «Шифры» → конкретный шифр → ввод параметров (аналогично для «Свойств» и «Калькулятора»). Текущий шаг каждого пользователя хранится в словаре `UsersPath` (`chatId → список введённых значений`), поэтому бот параллельно обслуживает нескольких пользователей, не путая их состояния. Введённый текст разбирается и передаётся в соответствующий метод библиотеки `Crypto` через словарь «название пункта меню → функция-обработчик» (`DictionaryMethods`). Отдельно обрабатываются некорректный формат ввода и обращения к несуществующим пунктам меню — бот не падает, а просит ввести данные заново.
